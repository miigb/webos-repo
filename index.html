📺 webOS Homebrew Channel Repository

miigb webOS App Store

Custom repository for LG webOS TV Homebrew Channel. Easily install ad-free YouTube and streaming tools directly on your TV.

Repository URL for Homebrew Channel
https://miigb.github.io/webos-repo/
How to add to your LG TV:
  1. Open Homebrew Channel on your LG TV.
  2. Click the Settings (⚙️) icon in the top right corner.
  3. Scroll down to Repositories and select Add Repository.
  4. Enter the URL above (or https://miigb.github.io/webos-repo/api/apps.json) and click Add.
  5. Go back to the Main screen — your apps are now ready to install with 1-click!
